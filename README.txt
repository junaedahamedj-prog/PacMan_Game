PAC-MAN ARCADE EDITION  (Java Swing)

RUN (Java 11 or newer)
  cd PacManJava
  java PacManGame.java
or
  javac PacManGame.java
  java PacManGame

Run it from inside this folder so it can find images/ and fonts/.

YOUR OWN FILES (all optional)
  images/heart.png   heart for the lives. If missing, a heart is drawn in code.
  images/dev1.png    About Us photo for MD UDOY HOSSAIN JOY
  images/dev2.png    About Us photo for IMTIYAZ ALI
  images/dev3.png    About Us photo for JUNAED AHMED
                     (If a photo is missing, the letter U / I / J is shown.)
  fonts/PressStart2P-Regular.ttf and fonts/VT323-Regular.ttf
                     Same retro fonts as the HTML version (free on Google Fonts).
                     Without them a plain monospaced font is used.

CONTROLS  Arrows / WASD = move, P = pause, Enter/Esc = close a window.
